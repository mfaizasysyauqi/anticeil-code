## ⚡ Overview

**Anticeil Code** is an autonomous coding extension for VS Code forked and tailored from the Cline open-source foundation. It pairs seamlessly with the **Anticeil Studio** ecosystem:

- 🧠 **Agentic Precision & Multi-file Diffing**: Plans, inspects, and executes multi-file patches with rollback safety.
- 📐 **Docs Studio Integration**: First-class co-authoring for LaTeX, Typst, Markdown, and TypeScript.
- 🔑 **Zero-Telemetry BYOK**: Bring your own keys (OpenAI, Anthropic Claude 3.7/Sonnet, Google Gemini 2.5/Flash, DeepSeek, Ollama, OpenRouter).
- 🔌 **Model Context Protocol (MCP)**: Native integration with Smithery, local MCP servers, and Anticeil dev tools.

## 🚀 Getting Started

### Local Development

\\\powershell
# 1. Install dependencies
bun install

# 2. Run VS Code Extension Development Host
cd apps/vscode
bun run dev
\\\

Press **F5** in VS Code to launch the **Extension Development Host** with Anticeil Code loaded.
